Ce que ce site collecte

Ce site n’utilise ni cookie de suivi, ni outil de mesure d’audience, ni publicité. Il ne conserve aucune information saisie dans ses formulaires.

Votre choix de thème

Si vous choisissez le mode clair ou sombre, ce choix est enregistré dans votre navigateur pour vos prochaines visites. Il reste sur votre appareil et n’est jamais transmis à SOTGEC.

Les formulaires de contact

Le texte que vous saisissez s’ouvre dans WhatsApp ou dans votre messagerie. Vous le relisez, puis vous décidez de l’envoyer. SOTGEC ne reçoit que le message que vous envoyez vous-même.
